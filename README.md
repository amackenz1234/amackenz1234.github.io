# Nativ

Build native iOS apps with AI — cloud Xcode compiler and App Store Connect submit demo for GitHub Pages.

## Sample project (Electro Cycles)

The GitHub Pages site is the Nativ builder. This repo also includes a real SwiftUI catalog you can generate from the prompt “Electro Cycles shop”:

- Native iOS catalog app: [`ios/ElectroCycles`](ios/ElectroCycles)
- Catalog MCP server: [`mcp/electro-cycles`](mcp/electro-cycles) (wired in [`.cursor/mcp.json`](.cursor/mcp.json))
- GitHub Actions macOS CI for the iOS app: [`.github/workflows/ios.yml`](.github/workflows/ios.yml)
